

# Full-Stack Application - She Can Foundation Task

A secure and responsive Full-Stack application engineered using a Node.js and Express runtime architecture. The system features an internship application submission form designed precisely around the corporate brand guidelines of the She Can Foundation.

## 🚀 Features

- **Local JSON Database:** Persists data locally in a flat-file stream (`submissions.json`) avoiding external setup friction.
- **Dual-Layer Validation:** Immediate front-end form validation backed by strict server-side validation checks.
- **Secure Admin Portal:** A dedicated credential login gate (`login.html`) utilizing header authorization to protect administrative data.
- **Data Management Layout:** Real-time log filtering with an active character-matching search bar and individual data entry deletion.
- **Responsive Branding Design:** Written entirely in vanilla CSS (`style.css`), optimized offline with zero framework dependencies.
